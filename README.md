# Site Amor ❤️

## Publicação
Envie todo o conteúdo desta pasta para o repositório do GitHub Pages.

- `index.html`
- `grito.mp3`
- `musica.mp3`
- `assets/`

Não renomeie nem remova a pasta `assets`.

## Mural de recados
Os recados são salvos no `localStorage` do navegador. Isso significa que ficam salvos no dispositivo/navegador em que foram adicionados.

Para um mural realmente compartilhado entre dois celulares/computadores, será necessário conectar o site a um banco de dados, como Supabase ou Firebase.

## Áudio do botão Não
O áudio `grito.mp3` toca quando o botão "Não" é alcançado/passado pelo cursor e também quando é tocado/clicado. O código evita repetir o áudio várias vezes em sequência.
